Sample Dialog Box

The following macro code generates a dialog box which contains
examples of all the various types of dialog box functions.  
Detailed explanations of the functions within this macro can 
be found in the ReportBasic on-line help.

The value contained within a variable as a result of selecting
a Radio Button, Push Button, List Box item, or Drop-Down List 
Box item is 0 for the first item, 1 for the second, etc.  The
variable value for a Check Box is 0 unchecked, 1 checked.  
The variable value for a Text Box is the value typed into the
Text Box.  To use a dialog box variable as a part of another 
ReportBasic statement, the variable name must be preceded by 
the dialog box name,  i.e. (Test_Box.RadioValue).  


Sub Sample_Dialog_Box()

'Values to populate the list boxes
ListValue$ = "Lucy"+Chr$(13)+"Ricky"+Chr$(13)+"Fred"+
Chr$(13)+"Ethel"

'An error routine is necessary for the Cancel Button to 
'function correctly
On Error GoTo Cancel:

'All of the following functions are described in detail in the
'ReportBasic on-line help
Begin Dialog Samp_Dialog 275,200

   Caption "Sample Dialog Box"

   GroupBox 15,10,60,60, "Radio Buttons"
   OptionGroup .RadioValue
   OptionButton 25,25,40,12,"Larry"
   OptionButton 25,37,40,12,"Moe"
   OptionButton 25,49,40,12,"Curly"
