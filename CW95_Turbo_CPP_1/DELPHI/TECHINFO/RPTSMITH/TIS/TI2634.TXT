Conditionally writing data out to a delimited text file

The follow macro examples show how to conditionally write a field in
a record out to a delimited text file.  All of the examples are
report macros that are linked to "After the Report is Open"



'Testing the value of a numeric field. If the condition is true, the
'EMPLOYEE_ID is written out to a file.

Sub out2file()
Open "C:\tempdata\test.txt" for output as 1
GetRandom 1

for x = 1 to RecordCount()

   if Val(Field$("PRICE")) > 5 then
      a$ = Field$("EMPLYEE_ID")
      Write #1,a$
   end if
   GetNext

next x

Close #1

End Sub

Sub out2file4()
n = 1
ReDim values$(RecordCount())
GetRandom 1

for x = 1 to RecordCount()
   if Val(Field$("MAC_TOTAL")) > 25 then
      values$(n) = Field$("EMPLYEE_ID")
   n = n + 1 
   end if
   GetNext
next x

open "c:\tempdata\test4.txt" for output as #4

for y = 1 to n
   Write #4,values$( y )
next y
