Summarizing Macro Derived Fields

The following are examples of Macro Derived Fields that will 
sum the values of another Macro Derived Field.  In the 
examples, substitute the field name of the Marco Derived Field 
to be summarized in place of "MDF."  Also, substitute the name 
of the of the field that data is grouped on, in place of 
"GROUP," if you are working with grouped data.  If the report 
is grouped on more than one field, and you want a summary for 
each group, create a Macro Derived Field for each group. 

Macro #1  (Summarize the value of another Macro Derived Field 
in a report with no group breaks.)


Sub sum_mac()

while Current() > 1
   TOTAL = TOTAL + Val(Field$("MDF"))
   GetPrevious
wend

if Current() = 1 then TOTAL = TOTAL + Val(Field$("MDF"))

DerivedField Str$(TOTAL)

End Sub
