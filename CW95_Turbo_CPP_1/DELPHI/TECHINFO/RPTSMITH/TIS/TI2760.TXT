ReportSmith v2.5
Network Installation Guide
 
 
This document provides step-by-step instructions for installing
ReportSmith with various types of network configurations.  For
reasons associated with network access and security, these
installation procedures should be performed by the network
administrator.  
 
Please read the ReportSmith Getting Started Guide, Chapter 2
"Installation" and Chapter 3 "Connecting to Data Sources" prior
to starting the installation process.
 
The following network configurations are covered by this
installation guide:
 
1.   Windows is installed locally and ReportSmith is being 
     installed on the network.
 
2.   Windows is installed on the network and ReportSmith is being
     installed on either a network or local drive.
 
 
To begin the ReportSmith installation for either configuration:
 
1.   Start Windows.
 
2.   Insert Disk 1 into your floppy drive.  From the Program
     Manager main menu, choose File | Run. 
 
3.   In the command line text box, type A:\INSTALL (or 
     B:\INSTALL) and choose OK.
 
4.   Select Custom and choose Continue.  
 
5.   Specify the location for the ReportSmith files. (e.g.,
     F:\RPTSMITH)

6.   Specify the location for the ODBC files. (e.g., F:\ODBC)
 
7.   Specify the location for the OLE files. (e.g., F:\OLE)
 
8.   Choose Set Options and select the files and connections you 
     want installed. Choose Continue, then choose Continue again.
 
9.   Specify the location for the IDAPI files. (e.g., F:\IDAPI)
 
10.  Choose Continue, then choose Install. When prompted, insert

11.  All users must load the DOS command SHARE before starting

                       IDAPI CONFIGURATION
 
The IDAPI (Integrated Database Application Programming Interface)
configuration file (IDAPI.CFG) holds IDAPI configuration 
information: aliases, system and table parameters, and location 
of the network control file (for use when accessing Paradox 
tables).  IDAPI clients, like Paradox 5.0 for Windows and dBASE 
for Windows, will share IDAPI files.  The IDAPI configuration 
file is located in the directory specified during installation
(usually the same as the IDAPI files, see step 9 above).  You 
must run the IDAPI Configuration Utility to specify the location
of the network control file even if you are not using IDAPI 
client tables.
 
To run the IDAPI Configuration Utility:
 
1.   From the ReportSmith program group, double-click the IDAPI
     Configuration Utility icon.  The IDAPI Configuration Utility
     dialog box appears.
 
2.   Highlight the Paradox Driver and enter the location of the 
     network control file directory in the NET DIR parameter.  
     This should point to the same network directory specified in

     PXENGCFG.EXE.  If you will not be accessing Paradox tables, 
     NET DIR should contain the default entry of C:\.   
 
3.   To set up aliases that will be common for all users, click
     the Aliases tab, and choose New Alias.
 
4.   Choose File | Save to save these changes to the IDAPI.CFG
     file.
 
5.   Choose File | Exit to exit the IDAPI Configuration Utility.
 
Note:  If users want or need their own IDAPI.CFG file (e.g., for 
       personal aliases), copy the existing IDAPI.CFG file into
       their own Windows directory.  Have each user run the IDAPI
       Configuration Utility, choose File | Save As and specify
       the location of their IDAPI.CFG (e.g., 
       C:\WINDOWS\IDAPI.CFG).  To verify the use of a particular
       IDAPI.CFG file, check the [IDAPI] section of the WIN.INI
       file.  It should have the following:
 
       [IDAPI]
       CONFIGFILE01=F:\WINAPP\IDAPI\IDAPI.CFG
       DLLPATH=F:\WINAPP\IDAPI
  
       An advantage to users having their own IDAPI.CFG file is
       that they can make changes to their own configurations in
       [IDAPI] without effecting other users; a disadvantage is
       that it is more difficult to administer, since they will
       be able to change their IDAPI configuration. 
 
6.   If you are installing ReportSmith SQL version, IDAPI may
     need to be added to each user's path.  If you try connecting
     to a SQL database and receive the message "Unable to load
     database access DLL", and you have followed the instructions
     in the "Getting Started" guide for your specific SQL
     database, add IDAPI to your path.  This should resolve this
     issue.

                  INSTALLING THE ODBC AND OLE DRIVERS 
 
 
The ODBC and OLE drivers can be made available to other users who
will be running ReportSmith from the network by installing them
in one of the following two ways:
 
 
ODBC and OLE Install Option 1: Have each user copy the ODBC and
OLE drivers from the network to their C:\WINDOWS\SYSTEM 
directory on their local hard drive.
 
1.   Copy ODBC.INI, ODBCINST.INI, ODBCISAM.INI, RPTSMITH.INI,
     RS_SQLIF.INI, and RPTSMITH.CON from the network
     administrator's C:\WINDOWS directory to a directory on the
     network. (e.g., F:\INI)
 
2.   Each network user should now install the INI files by 
     copying ODBC.INI, ODBCINST.INI, ODBCISAM.INI, RPTSMITH.INI,
     RS_SQLIF.INI, and RPTSMITH.CON from the network directory
     (e.g., F:\INI) to their C:\WINDOWS directory.
 
3.   Each network user should install the ODBC drivers by 
     copying the files from the network directory (e.g., F:\ODBC)
     to their C:\WINDOWS\SYSTEM directory.
 
4.   Each network user should install the OLE drivers by copying
     the files from the network directory (e.g., F:\OLE) to their
     C:\WINDOWS\SYSTEM directory.
 
5.   Each network user should copy the files PXENGCFG.EXE,
     PXENGWIN.DLL and CTL3DV2.DLL from the directory on the
     network (e.g., F:\WINSYS) to their local WINDOWS\SYSTEM

8.   Installation is now complete.

                 ReportSmith is being installed on either a
                 network or local drive.
 
Note: You must have Write access to the network directory where 
      Windows is installed to perform this installation.
 
1.   Launch a text editor such as Notepad; open the
     RPTSMITH.INI file which is located in the local Windows
     directory.

2.   Add the following line to the [ReportSmith] section and
     specify a drive and path where Write access is available,
     (e.g., TempDataPath=C:\dos\temp) This directory must be a
     valid directory and must be a different directory than that
     which is specified in the AUTOEXEC.BAT file "Set Temp="
     line. 
 
     This line specifies the location for ReportSmith temporary
     files to be written.  This line is necessary in the event
     that Write access is not available to the default location
     where ReportSmith will try to write temporary files.
 
3.   Verify that the BinaryPath= found in the [Macro] section
     is also pointing to a location where Write access is
     available.  (e.g., BinaryPath=C:\dos\temp)
 
4.   Save the changes to the RPTSMITH.INI file.
 
 
Note: If ReportSmith has been installed locally, skip the 
remaining instructions.
 
5.   For additional users who will be running ReportSmith from 
     the network, have them create a new program group called
     "ReportSmith" and a new program item for the ReportSmith
     application. Type the name of the ReportSmith executable
     with the correct drive letter and path into the Command
     Line text box of the Properties dialog box.  (e.g.,
     F:\RPTSMITH\RPTSMITH.EXE)  The working directory should
     also be specified.  (e.g., F:\RPTSMITH)
 
Note: If access to ODBC drivers for other network users is not 
necessary, skip steps 6 through 9.
 
6.   Copy the ODBCINST.INI file, which is found in the
     local Windows directory, to a location on the network 
     where other users can have access to it.

7.   Each user should then copy the ODBCINST.INI file to their
     local Windows directory.
 
8.   Each user should launch the ODBC Administration Program to 
     add and configure ODBC data sources. To do this, launch
     ReportSmith and choose File | ODBC Setup.  More information

     the Connection File text box, specify the location of the
     RPTSMITH.CON file as being in the local Windows
     directory (e.g., C:\WINDOWS\RPTSMITH.CON) and choose OK.
 
13.  Close ReportSmith.
 
14.  Each network user should repeat steps 2 and 4.
 
15.  Installation is now complete.

                   ASSIGNING NETWORK RIGHTS
                                    
In order for ReportSmith to run properly, users must have the
proper rights to the various directories accessed by
ReportSmith.  The names of rights on various networks differ. 
The following is a list that describes the minimum rights each
user must have after all installation steps have been completed. 
See your network documentation for information on how to set
these rights.  For reference, the rights for Netware are given in
parenthesis:
 
RPTSMITH  Read files, Open files, search in the directory
          (READ, FILESCAN)
 
IDAPI     Read files, Open files, search in the directory
          (READ, FILESCAN)
 
If each user is running the ODBC and OLE drivers from a single
network installation the following applies:
 
ODBC      Read files, Open files, search in the directory
          (READ, FILESCAN)
 
OLE       Read files, Open files, search in the directory
          (READ, FILESCAN)
