ReportSmith v2.02a
Network Installation Guide
 
 
This document provides step-by-step instructions for installing
ReportSmith with various type of network configurations.  For
reasons associated with network access and security, these
installation procedures should be performed by the network
administrator.  The following network configurations are
covered by this installation guide:
 
1.   Windows is installed locally and ReportSmith is being
     installed to the network.
2.   Windows is installed on the network and ReportSmith is
     being installed to either a network or local
     drive.
 
 
Configuration 1:    Windows is installed locally and
ReportSmith is being installed to the network.
 
1.   Follow the installation instructions as specified in the
     ReportSmith Installation Guide, selecting a network drive
     as the location for ReportSmith.
 
Note:     The ODBC drivers, by default, will be installed to
          the C:\WINDOWS\SYSTEM directory on the local hard
          drive.
 
The ODBC drivers can be made available to other users who
will be running ReportSmith from the network by installing
them in one of the following two ways:
 
     ODBC Install Option 1:   Have each user install the
                              ODBC drivers from the network
			      to the C:\WINDOWS\SYSTEM

Configuration 2:    Windows is installed on the network and
                    ReportSmith is being installed to either a
                    network or local drive.
 
Note:     You must have Write Access to the network directory
          where Windows is installed to perform this
          installation.
 
1.   Follow the installation instructions as specified in the
     ReportSmith Installation Guide, selecting a either a local
     or network drive as the location for ReportSmith.
 
2.   Launch a text editor such as Notepad, open the
     RPTSMITH.INI file which is located in the personal Windows
     directory.
 
3.   Add the following line to the [ReportSmith] section and
     specify a drive and path where Write access is available,
     i.e.
 
          TempDataPath=C:\dos\temp
 
     This line specifies the location for ReportSmith temporary
     files to be written.  This line is necessary in the event
     that Write Access is not available to the default location
     where ReportSmith will try to write temporary files.
 
4.   Verify that the BinaryPath= found in the [Macro] section
     is also pointing to a location where Write access is
     available, i.e.
          BinaryPath=C:\dos\temp
 
5.   Save the changes to the RPTSMITH.INI file.
