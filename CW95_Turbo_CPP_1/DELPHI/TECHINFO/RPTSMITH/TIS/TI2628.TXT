    TITLE  :  Replacing a Table




Replacing a Table
 
The following macro example replaces the existing table in a 
report with a different table. This is a Report Macro linked 
to the "After Report Open" event.
 
Sub change_table()
 
DIM KC as DataSet
 
'applies the dataset object to the active SQL statement
KC.SetFromActive
 
Current_Table$ = "C:\rptsmith\texttest\dept1.csv"
New_Table$ = "C:\rptsmith\texttest\dept2.csv"
 
'replace the table
KC.ReplaceTable Current_Table$,"",New_Table$,""
 
'Re-execute the SQL statement with the new table
Recalc 
 
End Sub
