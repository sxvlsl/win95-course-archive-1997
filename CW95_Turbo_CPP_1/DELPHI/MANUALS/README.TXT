Delphi 1.0 Online Manuals
--------------------------

The *.PDF files in this directory are the Delphi 1.0 
manuals. To read them you'll need to install the 
latest Adobe Acrobat Reader program from Adobe 
Systems Incorporated.

To install the latest version of the Acrobat Reader 
run this setup program from the Delphi 2.0 CDROM:
\INFORM\ACROREAD\DISK1\SETUP.EXE

Once Acrobat is installed, you can use it to read 
both the Delphi Informant files in the \INFORM 
directory and to read the Delphi 1.0 Online Manuals 
in this directory.
