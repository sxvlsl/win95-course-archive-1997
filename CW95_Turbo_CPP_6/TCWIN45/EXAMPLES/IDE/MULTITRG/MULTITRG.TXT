This project is an example of multi-targeting in the new project manager.

The two targets in this project, multitrg.exe, differ slightly. The first
target has local options that turns off debugger information and specifies
the output directories to point to .\out. The Options|Project pages involved
are Directories, Compiler|Debugging and Linker|General. 
The second target builds with full debugger information and uses local options
on the Options|Project|Directories page to specify .\outdb as the output path.

Build both targets and compare the sizes. Try debugging each one.

The targets were created by
1) selecting Project|New Target,
2) typing "multitrg" in the 'Target Name' field,
3) selecting 'Standard' from the 'Target Type' list,
4) selecting 'Ok'

This leads to TargetExpert where:
5) "Windows 3.x (16 bit)" is selected in the 'Platform' list
6) selecting 'Ok' will complete the target.

Repeat steps 1-6 to add the second target.

To redirect output and turn off debugger info on the first target: 
7) Right click on the first target
8) Select 'Local Options' with brings up the Multi-Page-Dialog
9) In the 'Directories' section entering 'out' in the 'Intermediate'
and 'Final output' fields.
10) Now go to the Compiler section of the MPD and select the 'Debugging' page,
uncheck 'Debug information in OBJs' and 'Browser reference information in OBJs'
11) Select 'Ok'

To redirect output on the second target to the 'outdb' directory
12) Right click on the first target
13) Select 'Local Options' with brings up the Multi-Page-Dialog
14) In the 'Directories' section entering 'outdb' in the 'Intermediate'
and 'Final output' fields.
15) Select 'Ok'

You should note that the source nodes under both executables are copied
under each target. If you wanted to add a source module you would have to
do so (in this project) in two places to keep your debug and non-debug targets
in synch. To get relief see the example in the SrcPool directory.
